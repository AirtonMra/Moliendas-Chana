# Imágenes pendientes

El sitio no incluye fotografías. Cada lugar donde va una foto muestra un marcador visible con el nombre de archivo esperado.
**Copiá la foto en esta carpeta con ese nombre exacto y aparece sola, sin editar el HTML.**

Recomendaciones: JPG o WebP optimizado (ideal < 250 KB; ancho máx. 1600 px para portadas y 1200 px para el resto).
Si usás otra extensión, cambiá el nombre en el atributo `data-src` del HTML.

Provisorios incluidos: `logo.svg`, `logo-claro.svg` (reemplazar por el logotipo original) y `favicon.svg`.
